# Dart Fundamentals: School Supplies Budget

Student: Angelyn J. Sopera  
Course: NTC_PC16 – Mobile Development w/ Lab

Description
This program calculates the cost of notebooks, checks whether the purchase is within a budget, and demonstrates Dart variables, data types, and operators.

Concepts Used
- int, double, String, and bool
- Arithmetic operators (*, -)
- Comparison operator (<=)
- Integer division (~/) and remainder (%)
- Console output using print() and string interpolation
